# Store — the career knowledge base

Agent-maintained markdown. Format, ID scheme, and rules: `specs/store-conventions.md`. Read that spec before writing here. Entities carry permanent IDs (`{pos-001}` style); position_id is the cross-reference spine; tags come from `tags.md`. Humans may edit anything but never need to — the nightly hygiene job and the skills do the maintenance.

Populated by the Phase 3 bootstrap (CV + intro doc + lists Excel + OneDrive archive + LinkedIn export), then grown by every `/apply` cycle.
